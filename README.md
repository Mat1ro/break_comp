# Телепорт курсора

## Быстрая установка на другой Mac — без Git

Нужен установленный **Python 3.9+** и доступ в интернет. Вставьте в терминал:

```sh
curl -fsSL https://raw.githubusercontent.com/Mat1ro/break_comp/main/install-macos.sh -o /tmp/install-break-comp.sh && bash /tmp/install-break-comp.sh
```

Установщик сам скачает проект, создаст окружение, установит зависимости и
запустит программу с автозапуском. Приложение `.app` не создаётся.
Повтор этой команды обновляет установленную версию. Зависимости скачиваются
автоматически; скорость зависит от интернета. Используется интервал из скачанной
версии `main.py`.

Установка, запуск и остановка выполняются без вывода в stdout. Ошибки остаются
в stderr. Команды `autostart.py status`, `preview` и справка `--help` также
выводят результат в stderr. Успешная установка заканчивается возвращением
приглашения терминала; эффекты включатся через одну минуту.

При первом запуске разрешите управление мышью в настройках macOS →
«Конфиденциальность и безопасность» → «Универсальный доступ», если это требуется.
Один переход по ссылке не может сам запустить код на Mac — команду нужно
выполнить в терминале.

Остановить установленную этим способом программу:

```sh
"$HOME/Library/Application Support/break_comp/current/.venv/bin/python" "$HOME/Library/Application Support/break_comp/current/autostart.py" stop
```

Чтобы также отключить автозапуск, замените `stop` на `uninstall`.
Файлы хранятся в `~/Library/Application Support/break_comp/`; прежние версии
сохраняются. Установка использует тот же LaunchAgent, что и ручной способ ниже.

## Как работает программа

После каждого запуска программа **ждёт 1 минуту (60 секунд)**. В это время
курсор не двигается, звук не воспроизводится и громкость не меняется.
Затем курсор мгновенно перемещается в случайную точку основного экрана каждые
**0,1 секунды**. **Клики полностью отключены.** Работает, пока её не остановят.

На macOS за курсором появляется **радужный след** из светящихся точек,
которые плавно исчезают за 0,8 секунды. След включается после той же
минутной задержки, отображается поверх окон и пропускает нажатия мыши.
Он работает на подключённых экранах; точки телепортации по-прежнему выбираются
на основном экране. В защищённых системных окнах эффект может быть не виден.
Отдельный фоновый процесс `cursor_trail.py --child` рисует след и автоматически
закрывается вместе с основным процессом, включая обычные команды остановки.
Новые зависимости для следа не нужны. На Windows и Linux след не отображается.

На macOS дополнительно каждые **10 секунд** воспроизводится
`assets/farts-8.mp3`. Первый звук — после общей минутной задержки,
следующие — каждые 10 секунд. Перед каждым
воспроизведением системная громкость устанавливается на **100%**, mute отключается.
Это меняет громкость текущего устройства вывода для всей системы; после остановки
громкость автоматически не восстанавливается. Некоторые внешние аудиоустройства
регулируются только аппаратно.

Звук работает независимо от курсора. При остановке через Ctrl+C, `stop`,
`uninstall` или обычный `kill PID` завершается и воспроизведение.
Аудиофайл входит в репозиторий и автоматически скачивается установщиком.

Нужен Python 3.9 или новее.

На macOS программа работает без значка Python в Dock и переключателе Cmd+Tab.
Остановить её можно через Ctrl+C при ручном запуске или командами ниже
при фоновом запуске. В «Мониторинге системы» процесс остаётся видимым.

## Скачать и запустить на другом устройстве

1. Установите Python 3.9 или новее, если его ещё нет.
2. Скачайте [ZIP проекта](https://github.com/Mat1ro/break_comp/archive/refs/heads/main.zip)
   и распакуйте. Откройте терминал в папке `break_comp-main`.
   Если используете Git, вместо ZIP выполните:

   ```sh
   git clone https://github.com/Mat1ro/break_comp.git
   cd break_comp
   ```

3. На macOS выполните:

   ```sh
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   .venv/bin/python main.py
   ```

   На Windows:

   ```powershell
   py -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe main.py
   ```

Первое перемещение, след и звук начнутся через **1 минуту**. Остановка — **Ctrl+C**;
она работает и во время ожидания.
Для автозапуска на другом Mac сначала остановите ручной запуск через Ctrl+C,
затем выполните `.venv/bin/python autostart.py install`. Настройка автозапуска
выполняется отдельно на каждом устройстве.

Чтобы остановить фоновую программу на Mac до следующего входа в macOS,
выполните из папки проекта:

```sh
.venv/bin/python autostart.py stop
```

Чтобы остановить её и полностью отключить автозапуск:

```sh
.venv/bin/python autostart.py uninstall
```

## Запуск на macOS

В терминале из папки проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 main.py
```

Если установленный через Homebrew Python выдаёт ошибку `pyexpat` при создании
окружения, можно использовать системный Python: `/usr/bin/python3 -m venv .venv`.

При следующих запусках достаточно:

```sh
source .venv/bin/activate
python3 main.py
```

Если macOS блокирует управление курсором, разрешите приложению, из которого
запущен скрипт (например, Terminal), управление компьютером в системных
настройках → «Конфиденциальность и безопасность» → «Универсальный доступ».
После изменения разрешения перезапустите приложение и скрипт.

## Остановка

- При ручном запуске нажмите **Ctrl+C** в терминале, где запущена программа.
- Для фонового запуска на Mac используйте `.venv/bin/python autostart.py stop`.
  Автозапуск сохранится: программа снова запустится при следующем входе в macOS.
- Чтобы также удалить автозапуск, используйте `.venv/bin/python autostart.py uninstall`.

Все команды выполняются из папки проекта. Перемещение курсора в любой угол
экрана, включая правый верхний, не останавливает программу.

## Автозапуск на macOS

После установки зависимостей выполните из папки проекта:

```sh
.venv/bin/python autostart.py install
```

Команда запускает программу сейчас и настраивает запуск при каждом входе
в вашу учётную запись macOS, в том числе после перезагрузки MacBook.
После каждого запуска, включая повторный `install`, курсор, след и звук ждут 1 минуту.
Терминал можно закрыть. До входа в учётную запись программа не работает.
Используется пользовательский [LaunchAgent](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html), без `sudo`.

Проверить состояние:

```sh
.venv/bin/python autostart.py status
```

Остановить до следующего входа в macOS:

```sh
.venv/bin/python autostart.py stop
```

Остановить и полностью отключить автозапуск:

```sh
.venv/bin/python autostart.py uninstall
```

Для повторного запуска выполните `install` ещё раз. Он также обновляет
настройку после перемещения проекта. Папка проекта и `.venv` должны оставаться
на диске.

Настройка хранится в `~/Library/LaunchAgents/io.github.mat1ro.break-comp.plist`,
ошибки — в `~/Library/Logs/break_comp/stderr.log`. Stdout фонового процесса
направлен в `/dev/null`; старый `stdout.log`, если он есть, не удаляется.
Чтобы применить настройку к уже установленному агенту, повторите `install`.
Если агент запущен, но курсор неподвижен,
проверьте «Конфиденциальность и безопасность» → «Универсальный доступ»:
фоновому Python может потребоваться отдельное разрешение. После выдачи
разрешения повторите команду `install`.

Закрытие крышки обычно переводит MacBook в сон. При открытии крышки и
разблокировке существующий процесс продолжает работу; повторный вход для этого
не нужен. Если дисплей временно недоступен, программа ждёт его восстановления
и повторяет попытку каждые 0,1 секунды.

На macOS курсор перемещается системной функцией
[CGWarpMouseCursorPosition](https://developer.apple.com/documentation/coregraphics/cgwarpmousecursorposition(_:)).
Программа проверяет фактическую позицию после команды. Если она не совпала
с заданной, предупреждение записывается в `stderr.log`. Статус `running`
сам по себе не подтверждает движение.

## Другие системы

На Windows создайте окружение командой `py -m venv .venv`, затем выполните
`.venv\Scripts\python.exe -m pip install -r requirements.txt` и
`.venv\Scripts\python.exe main.py`.

На Linux нужен графический сеанс X11; команды запуска такие же, как на macOS.
В зависимости от дистрибутива могут понадобиться системные пакеты Tkinter
и Python development headers. Wayland не поддерживается этим проектом.

Используется [PyAutoGUI](https://pyautogui.readthedocs.io/en/latest/quickstart.html).
Случайные точки выбираются внутри основного экрана, с отступом в один пиксель
от края.
