# Телепорт курсора

После запуска программа ждёт 5 секунд, затем каждые 5 секунд мгновенно
перемещает курсор в случайную точку основного экрана. Работает, пока её не остановят.

Нужен Python 3.9 или новее.

## Запуск на macOS

В терминале из папки проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 main.py
```

Если установленный через Homebrew Python выдаёт ошибку `pyexpat` при создании
окружения, можно использовать системный Python: `/usr/bin/python3 -m venv .venv`.

При следующих запусках достаточно:

```sh
source .venv/bin/activate
python3 main.py
```

Если macOS блокирует управление курсором, разрешите приложению, из которого
запущен скрипт (например, Terminal), управление компьютером в системных
настройках → «Конфиденциальность и безопасность» → «Универсальный доступ».
После изменения разрешения перезапустите приложение и скрипт.

## Остановка

- Нажмите **Ctrl+C** в терминале, где запущена программа.
- Или вручную переместите курсор в левый верхний угол основного экрана
  и оставьте там: программа завершится при следующей попытке перемещения,
  не позднее чем примерно через 5 секунд.

## Автозапуск на macOS

После установки зависимостей выполните из папки проекта:

```sh
.venv/bin/python autostart.py install
```

Команда запускает программу сейчас и настраивает запуск при каждом входе
в вашу учётную запись macOS, в том числе после перезагрузки MacBook.
Терминал можно закрыть. До входа в учётную запись программа не работает.
Используется пользовательский [LaunchAgent](https://developer.apple.com/library/archive/documentation/MacOSX/Conceptual/BPSystemStartup/Chapters/CreatingLaunchdJobs.html), без `sudo`.

Проверить состояние:

```sh
.venv/bin/python autostart.py status
```

Остановить до следующего входа в macOS:

```sh
.venv/bin/python autostart.py stop
```

Остановить и полностью отключить автозапуск:

```sh
.venv/bin/python autostart.py uninstall
```

Для повторного запуска выполните `install` ещё раз. Он также обновляет
настройку после перемещения проекта. Папка проекта и `.venv` должны оставаться
на диске. Аварийная остановка через угол экрана сохраняется: автоматического
перезапуска после неё нет до следующего входа в macOS.

Настройка хранится в `~/Library/LaunchAgents/io.github.mat1ro.break-comp.plist`,
логи — в `~/Library/Logs/break_comp/`. Если агент запущен, но курсор неподвижен,
проверьте «Конфиденциальность и безопасность» → «Универсальный доступ»:
фоновому Python может потребоваться отдельное разрешение. После выдачи
разрешения повторите команду `install`.

Закрытие крышки обычно переводит MacBook в сон. При открытии крышки и
разблокировке существующий процесс продолжает работу; повторный вход для этого
не нужен. Если дисплей временно недоступен, программа ждёт его восстановления
и повторяет попытку каждые 5 секунд.

На macOS курсор перемещается системной функцией
[CGWarpMouseCursorPosition](https://developer.apple.com/documentation/coregraphics/cgwarpmousecursorposition(_:)).
Программа проверяет фактическую позицию после команды. В `stdout.log` появляется
«Перемещение курсора подтверждено» при первом успешном перемещении и после
восстановления работы. Статус `running` сам по себе не подтверждает движение.

## Другие системы

На Windows создайте окружение командой `py -m venv .venv`, затем выполните
`.venv\Scripts\python.exe -m pip install -r requirements.txt` и
`.venv\Scripts\python.exe main.py`.

На Linux нужен графический сеанс X11; команды запуска такие же, как на macOS.
В зависимости от дистрибутива могут понадобиться системные пакеты Tkinter
и Python development headers. Wayland не поддерживается этим проектом.

Используется [PyAutoGUI](https://pyautogui.readthedocs.io/en/latest/quickstart.html).
Случайные точки выбираются внутри основного экрана, без крайнего ряда пикселей,
чтобы программа сама не активировала аварийную остановку.
